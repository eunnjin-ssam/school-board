# 나이스 인증서 자동로그인 — 지시문

이 문서는 `neis-login/` 폴더의 나이스 자동로그인을 다시 만들거나 고칠 때 AI(Claude 등)나 사람에게 그대로 건네는 지시문이에요.
아래 요구사항과 규칙을 지키면서 작업하세요.

---

## 1. 목표

학교 PC에서 단추 하나(스쿨보드 바로가기 또는 `나이스-로그인.cmd` 더블클릭)로 서울 나이스에 인증서 로그인을 끝까지 자동으로 한다.
선생님은 마우스를 움직이거나 암호를 칠 필요가 없어야 한다.

- 나이스 주소: `https://sen.neis.go.kr/jsp/main.jsp`
- 첫 화면의 **«인증서 로그인»** 버튼을 자동으로 누른다.
  - 이 버튼은 `<button>`이 아니라 `role="button"`인 `div`(`class="btn-login …"`)이고, 안의 글자가 «인증서 로그인»이다. `getByRole('button', { name: '인증서 로그인' })`로 찾는다.
- 인증서 목록에서 이름에 **«김은진»**이 들어간 인증서를 고른다.
  - 목록의 사용자 칸은 `div[title="…"]`이다. 이름 **일부만** 맞아도 고르도록 `div[title*="김은진"]`으로 찾는다.
  - 이름이 들어간 인증서가 여러 개면 **고르지 않고 암호도 넣지 않는다**.
- 인증서 줄을 먼저 클릭한 뒤 암호칸(`aria-label` 또는 `title`이 «인증서 암호 입력필드»)에 암호를 넣고 Enter를 누른다.
- «로그아웃» 글자가 보이면 로그인 성공으로 본다.

## 2. 암호 보관 — Windows 자격 증명 관리자

- 인증서 암호는 **파일로 저장하지 않는다.** Windows 자격 증명 관리자(현재 Windows 계정)의 **일반 자격 증명**에 넣는다.
  - 대상 이름: `SchoolBoard/NEIS-cert`
  - 종류 Generic, 보존 범위 LOCAL_MACHINE(이 컴퓨터의 이 계정)
- `cred.ps1`이 `advapi32`의 `CredWriteW / CredReadW / CredDeleteW / CredFree`를 불러 넣고, 꺼내고, 지운다.
  - 넣을 때는 `SecureString`을 바로 넘긴다(평문 문자열로 풀어 두지 않음).
  - 파일은 **UTF-8 BOM**으로 저장한다. Windows PowerShell 5.1이 한글을 깨뜨리지 않게 하기 위해서다.
- 암호는 `나이스-설정.cmd`(→ `setup.ps1`)에서 **선생님이 직접** 두 번 입력해 저장한다. AI가 대신 입력하거나 저장하지 않는다.
- 예전 방식의 파일(`%LOCALAPPDATA%\SchoolBoard\neis\cert.dat`)이 남아 있으면 설정할 때 지운다.
- `setup.ps1 -Remove`는 자격 증명, 설정, 나이스 전용 크롬 기록을 모두 지운다.

## 3. 설정 파일

- `%LOCALAPPDATA%\SchoolBoard\neis\config.json`에 둔다. 스쿨보드 폴더나 GitHub에는 두지 않는다.

  ```json
  { "neisUrl": "https://sen.neis.go.kr/jsp/main.jsp", "certName": "김은진", "looseSecurity": false }
  ```
- 설정이나 암호가 없어도 프로그램은 돌아간다. 이때는 버튼을 누르고 인증서까지 골라 둔 다음, 암호칸에 커서를 두고 선생님이 직접 암호를 치게 한다.

## 4. 실행 방식 — 검은 창 없이

- `나이스-로그인.cmd`는 `node login.mjs`를 **숨긴 창**으로 띄우고 바로 끝난다.

  ```
  powershell -NoProfile -WindowStyle Hidden -Command "Start-Process -FilePath node -ArgumentList 'login.mjs' -WorkingDirectory (Get-Location) -WindowStyle Hidden"
  ```
- `login.mjs`는 `playwright-core`로 **설치된 구글 크롬**(`channel: 'chrome'`)을 나이스 전용 프로필(`%LOCALAPPDATA%\SchoolBoard\neis\chrome-profile`)로 띄운다. 평소 쓰는 크롬과 섞지 않는다.
- 로그인 뒤에도 프로그램은 뒤에서 기다리다가 선생님이 크롬을 닫으면 같이 끝난다.
- 검은 창이 없으니, 막힌 일은 **Windows 알림 창**(PowerShell `MessageBox`, `DefaultDesktopOnly`)으로 알린다.
  - 알림 창을 `detached`로 띄우지 않는다. 프로그램이 끝나기 전에 알림 창이 닫힐 때까지 기다린다.

## 5. 반드시 지킬 안전 규칙

1. 암호는 암호칸에만 넣는다. 화면, 기록, 오류 메시지 어디에도 찍지 않는다. 오류 문구에 암호가 섞일 수 있으면 `●●●`로 가린다.
2. 암호를 넣은 뒤 로그인이 안 되면 **다시 시도하지 않는다.** 암호 오류 횟수 초과로 인증서가 잠기지 않게 하기 위해서다.
3. 막히면 크롬 창을 닫지 않고 그대로 둔다. 선생님이 직접 로그인할 수 있게 하고, 알림 창으로 이유를 알린다.
4. «인증서 로그인»을 눌렀는데 인증서 창이 안 뜨면(보안프로그램 로딩에서 멈춤), 암호를 넣기 **전**이므로 한 번만 보안 옵션을 바꿔 다시 띄운다. 성공하면 `looseSecurity: true`로 기억한다. 이 크롬 창으로는 나이스 말고 다른 사이트에 가지 않는다.
5. 나이스 전용 크롬이 이미 열려 있으면 새로 띄우지 않고 «이미 열려 있어요»라고 안내한다. 이때 크롬 오류는 `ProcessSingleton`이나 `Target page, context or browser has been closed`로 나온다.
6. GitHub에 올리지 않는 것: 암호, 인증서 이름이 든 설정, `neis-login/node_modules/`.

## 6. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `나이스-설정.cmd` → `setup.ps1` | Node.js 확인·설치, `npm install`, 나이스 주소·인증서 이름 입력, 암호를 자격 증명 관리자에 저장, 스쿨보드 단추 경로 복사 |
| `나이스-로그인.cmd` | `login.mjs`를 창 없이 실행 |
| `login.mjs` | 크롬 띄우기 → 버튼 누르기 → 인증서 고르기 → 암호 넣기 → 로그인 확인, 막히면 알림 창 |
| `cred.ps1` | 자격 증명 관리자 넣기·꺼내기·지우기 도우미 (setup과 login이 같이 씀) |
| `package.json` | `playwright-core` 1.64.1 (크롬은 이미 설치된 것을 씀) |

## 7. 새 컴퓨터에서 쓰는 법

1. GitHub에서 최신 내용을 받는다(`git pull`).
2. `나이스-설정.cmd`를 실행한다. 인증서 이름은 `김은진`, 암호는 직접 입력한다.
3. 스쿨보드 → [자주 쓰는 폴더·프로그램 추가]의 경로 칸에 `나이스-로그인.cmd` 경로를 붙여넣는다(설정이 끝나면 자동으로 복사돼 있음). 이름은 «나이스»로 한다.
4. 단추를 누르면 끝까지 자동으로 로그인된다.

학교 밖에서는 교육청 원격 접속(EVPN 등) 없이는 나이스가 열리지 않는다.
