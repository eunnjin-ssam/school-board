# 나이스 복무 자동화 — 지시서 (초안)

> 상태: **초안**. `【채워 주세요】` 표시는 선생님이 나이스 화면을 보고 알려 주실 부분이에요.
> 이 지시서가 다 채워지면 이 문서를 기준으로 다음 단계(프로그램 만들기)를 진행해요.
> 로그인은 [자동로그인-지시문.md](자동로그인-지시문.md)를 그대로 따르고, 이 문서는 로그인 **다음**부터를 다뤄요.

---

## 1. 목표

스쿨보드 화면에서 복무 내용을 입력하고 단추를 누르면, 나이스에 자동으로 로그인한 뒤 복무 신청서를 작성하고 **상신까지** 끝낸다.
복무 내역(남은 연가, 신청·결재 상태)도 스쿨보드에서 볼 수 있게 한다.

다루는 일:

| 종류 | 할 일 |
|---|---|
| A. 연가·조퇴·외출 | 신청서 작성 → 상신 |
| B. 출장 | 신청서 작성 → 상신 |
| C. 복무 내역 조회 | 남은 연가 일수, 신청 목록과 결재 상태를 읽어 와 스쿨보드에 보여 주기 |

다루지 않는 일(지금은): 초과근무, 결재(승인), 신청 취소·수정.

## 2. 흐름

```
스쿨보드 [복무] 카드에서 입력
   → [미리 보기] 입력 내용 요약 확인
   → [상신하기] 단추
   → 이 컴퓨터의 복무 도우미(127.0.0.1)로 전달
   → 나이스 전용 크롬 띄우기 + 자동로그인
   → 복무 메뉴로 이동 → 칸 채우기 → 결재선 확인 → 상신
   → 결과(성공/실패, 문서번호 등)를 스쿨보드에 돌려줌
```

## 3. 나이스 화면 정보 【채워 주세요】

### 3-1. 메뉴 경로
- 연가·조퇴·외출 신청: **기본 메뉴 > 복무 > 개인근무상황관리 > [신청]** ✅ 자동으로 여는 것까지 확인함 (`bokmu-probe.mjs`)
  - 왼쪽 메뉴의 글자 뒤에는 화면 읽기용 말이 숨어 있다(예: «복무 0단계 메뉴항목»). 그래서 글자 **앞부분**으로 찾는다: `.cl-text:visible` 중 `^복무(\s|$)`에 맞는 것.
  - «복무»가 이미 펼쳐져 있으면 다시 누르지 않는다(누르면 접힘).
  - 단추도 같은 방식으로 찾는다. «신청»은 `^신청(\s|$)`에 맞는 것만 누른다. «대리신청»·«변경신청»은 누르지 않는다.
  - [신청]을 누르면 새 창이 아니라 같은 화면 안에 **«근무상황신청» 대화상자**가 뜬다.
- 출장 신청: 【채워 주세요】
- 복무 내역 조회 / 남은 연가: 【채워 주세요】

### 3-2. 신청 화면의 칸 (화면 캡처를 주시면 정리할게요)

**근무상황신청 대화상자** (확인함)

맨 위에는 안내문, «근무상황신청목록»(행추가·행삭제), «근무상황사용현황»(가용연가·연가잔여일수·지각·조퇴·외출 누계)이 있다.
대화상자가 열리면 목록에 **오늘 연가 08:30~16:30 한 줄이 자동으로 생기고**, 아래 «근무상황신청입력»에서 그 줄을 고친다.

| 칸 (나이스 표기) | 화면 부품 | 넣을 값 |
|---|---|---|
| 근무상황 (목록 2개) | 콤보 ① 큰 갈래 + 콤보 ② 세부 (처음 값: 연가 / 연가) | 아래 «종류 → 근무상황» 표 |
| 연가종류 | 콤보 (처음 값: 금년도연가) | 그대로 둔다 |
| 기간 — 시작 | 날짜칸 `aria-label="신청기간 시작일자"` + 시 콤보 + 분 콤보 | 날짜 `2026-11-06` 꼴, 시·분은 **24시간제** (예: 15시 00분) |
| 기간 — 끝 | 날짜칸 `aria-label="신청기간 종료일자"` + 시 콤보 + 분 콤보 | 날짜 `2026-11-06` 꼴, 시·분 24시간제 (예: 16시 30분) |
| 일 / 시간 / 분 | 숫자칸 `aria-label="일"·"시간"·"분"` | 넣지 않는다 (나이스가 계산). 넣은 뒤 읽어서 맞는지 확인만 |
| 일반복 / 요일반복 | 체크칸 | 건드리지 않는다 |
| 연락처 | 틀 있는 입력칸 `aria-label="연락처"` (`(___)____-____`) | **항상 같은 번호**. 숫자 11자리를 넣는다. 번호는 이 컴퓨터 설정(`config.json`의 `phone`)에서 읽는다 — 저장소에는 적지 않음 |
| 사유 (글자칸) | 글자칸 `aria-label="사유 또는 용무"` | 조퇴·외출·지각: **항상 «개인 용무»** / 병조퇴·병외출·병지각: **항상 «병원 진료»** |
| 사유 (콤보 «선택») | 콤보 | 건드리지 않는다 (선생님 안내 없음) |
| 겸임기관 신청여부 | 체크칸 + 콤보 «선택» | 건드리지 않는다 |
| 비공개여부 | 체크칸 «기간»·«사유» | 6가지 모두(연가·병가 둘 다) **«사유»만 체크**한다. «기간»은 체크하지 않는다 |
| 단추 | **[승인요청]** = 상신, [닫기] | 맨 마지막에 [승인요청]을 **한 번** 누른다 |

**칸 채우는 순서** (선생님 확인)
1. 근무상황 콤보 ① → 콤보 ②
2. 기간: 시작 날짜 → 시 → 분, 끝 날짜 → 시 → 분
3. 연락처
4. 사유 글자칸
5. 비공개여부 «사유» 체크 (병조퇴·병외출·병지각도 똑같이)
6. 칸마다 실제로 들어간 값을 다시 읽어 맞는지 대조 (6장 2번). 일·시간·분이 나이스 계산과 맞는지도 확인
7. [승인요청]

- 분 콤보는 **5분 단위**(00, 05 … 55)다. 5분 단위가 아닌 분(예: 3시 12분)은 비슷한 값으로 바꾸지 않고 해석 실패로 표시한다.
- 콤보 목록은 화면에 보이는 근처 항목만 그려진다. 찾는 값이 없으면 목록을 위·아래로 굴려 가며 찾는다. 항목 글자는 `textContent` 로 읽는다.
- 체크칸·콤보는 화면 안 «글자» 로 찾는다 (예: 비공개여부 체크칸 = `.cl-checkbox` 중 글자가 «사유» 인 마지막 것). 시·분 콤보는 날짜칸과 **같은 줄의 오른쪽**에 있는 콤보로 찾는다.

**구현** — `bokmu-fill.mjs` ✅ 조퇴(15:00~16:30)·병조퇴(15:00~16:20)로 실제 나이스에서 채우기·대조까지 확인함 (승인요청은 누르지 않음)
```
node bokmu-fill.mjs --kind 병조퇴 --date 2026-11-06 --start 15:00 --end 16:20
```
- [승인요청]을 누른 뒤 나오는 확인창·인증서 창·완료 메시지는 【처음 상신할 때 확인 필요】.

**중복 확인** ✅ 확인함 — 칸을 채우기 전에 개인근무상황관리 목록(`[role=row]`, 대화상자 밖)에서 같은 신청을 찾는다.
- 같은 신청 = 기간 글자(`2026-11-06 14:30 ~ 2026-11-06 16:30`)와 근무상황 낱말이 **그대로** 같은 줄. «조퇴»가 «병조퇴»에 걸리지 않게 낱말 단위로 비교한다.
- 회수·반려·취소된 줄은 빼고 본다. 삭제여부 칸의 «미삭제»는 살아 있는 신청이다.
- 목록은 그 화면의 조회 기간(이번 달)만 보여 준다. 다른 달 신청은 여기서 걸러지지 않는다.

**승인요청** — `--submit yes` 를 붙여야만 누른다 (없으면 채우고 멈춤). 【실제 상신 시험 전】
- [승인요청]은 한 번만 누른다.
- 그 뒤: «…하시겠습니까» 확인창 → [확인]/[예] 한 번 / «…되었습니다·완료» → 닫고 성공 / 인증서 암호 창이나 처음 보는 창 → 아무것도 누르지 않고 멈춤.
- 끝나면 목록에 새 줄이 생겼는지 확인한 뒤에야 성공으로 알린다. 확인이 안 되면 다시 누르지 않는다.

**종류 → 근무상황 콤보 ①·②**

콤보 ①은 큰 갈래(처음 값 «연가»), 콤보 ②는 세부 항목이다. (선생님 확인)
- 콤보 ① «연가» → 콤보 ② 목록: 연가 / **조퇴 / 외출 / 지각**
- 콤보 ① «병가» → 콤보 ② 목록: 병가 / 공무상병가 / 반일병가 / **병지각 / 병조퇴 / 병외출** / 공무상병지각 / 공무상병조퇴 / 공무상병외출 / 공무상반일병가

| 종류 (선생님 말) | 콤보 ① | 콤보 ② (글자 그대로 고름) | 확인 |
|---|---|---|---|
| 조퇴 | 연가 (그대로) | 조퇴 | ✅ |
| 외출 | 연가 (그대로) | 외출 | ✅ |
| 지각 | 연가 (그대로) | 지각 | ✅ |
| 병조퇴 | 병가 | 병조퇴 | ✅ |
| 병외출 | 병가 | 병외출 | ✅ |
| 병지각 | 병가 | 병지각 | ✅ |

- 콤보 ②는 **글자가 정확히 같은 것**만 고른다. «병조퇴»를 고를 때 «공무상병조퇴»가 골라지면 안 된다.
- 콤보 ①을 바꾸면 콤보 ②의 목록이 바뀐다. 그래서 **① 먼저, ② 나중** 순서로 고른다.
- 콤보 ①이 «병가»면 연락처 옆에 **«기준병가상황»** 콤보(처음 값 «해당신청건»)가 생긴다. 건드리지 않는다.
- 연가일 때 보이는 «연가종류»(금년도연가)도 건드리지 않는다.
- 고른 뒤 두 콤보에 보이는 글자를 다시 읽어 맞는지 확인한다.

## 4. 스쿨보드 화면 (만들 것)

- 대시보드에 **[복무]** 카드를 새로 만든다.
  - 맨 위에 **문장 입력칸** 하나를 둔다. 선생님은 평소 말하듯 한 문장으로 적는다(4-1).
  - 탭: `신청` / `내역`
  - 비상연락처, 근무 시간처럼 매번 같은 값은 설정에 한 번만 저장한다.
- 문장을 적고 Enter를 누르면 해석한 결과를 **미리 보기 표**로 보여 준다(종류, 날짜, 시작~종료, 사유).
  - 표의 칸은 고칠 수 있다. 해석이 틀리면 선생님이 고친다.
  - 해석하지 못한 부분은 빨갛게 표시하고, [상신하기]를 막는다.
- 입력값 검사: 종료가 시작보다 빠르면 막기, 과거 날짜는 경고, 주말·공휴일은 경고.
- [상신하기]를 누르면 **요약 확인 창**을 띄우고, [예]를 눌러야 진행한다.

### 4-1. 문장 해석 규칙

선생님이 적는 문장 예:

| 문장 | 종류 | 날짜 | 시간 | 나이스 사유 칸 |
|---|---|---|---|---|
| 오늘 3시부터 4시20분까지 병원 가야 해서 조퇴 올려줘 | **병조퇴** | 오늘 | 15:00~16:20 | 병원 진료 |
| 내일 3시부터 은행업무로 조퇴 올려줘 | **조퇴** | 내일 | 15:00~16:30 | 개인 용무 |
| 오늘 2시반에 조퇴 올려줘 | **조퇴** | 오늘 | 14:30~16:30 | 개인 용무 |

**날짜**: 문장을 적은 날(오늘)을 기준으로 바꾼다.
- `오늘` / `내일` / `모레` / `글피`
- `월요일`·`이번 주 금요일` → 오늘 이후 가장 가까운 그 요일, `다음 주 화요일` → 다음 주의 그 요일
- `11월 20일`, `11/20`, `20일`(이번 달, 이미 지났으면 다음 달)
- 날짜 말이 없으면 **오늘**

**시각**: 근무 시간 안의 시각으로 읽는다.
- `1시`~`7시` → 오후(13:00~19:00), `8시`~`12시` → 오전·정오(08:00~12:00). `오전`·`오후`를 적으면 그대로 따른다.
- `2시반` = 14:30, `3시 10분`·`3시10분` = 15:10, `15:30`도 그대로 읽는다.
- `~부터`·`~에` → 시작 시각, `~까지` → 종료 시각
- 종료 시각이 없으면 **퇴근 시각**까지로 한다.

**종류**: 문장 속 낱말로 정한다.
- 다루는 종류는 **6가지뿐**이다: 조퇴·외출·지각 (개인 사정, 연가에서 깎임) / 병조퇴·병외출·병지각 (아파서, 병가).
- 기본 종류는 선생님이 적은 낱말을 따른다: `조퇴` / `외출` / `지각`. 셋 다 없으면 해석 실패로 표시한다.
- 사유에 **병원·진료·치료·검진·아파서·아픔·병** 같은 말이 있으면 앞에 «병»을 붙인다: 조퇴 → **병조퇴**, 외출 → **병외출**, 지각 → **병지각**.
- 그 밖의 사유(은행 업무 등)나 사유가 없으면 «병»을 붙이지 않는다: **조퇴** 등 (개인 사정).

**사유**: 문장 속 사유(병원, 은행 업무 등)는 **종류를 정하는 데만** 쓴다.
- 나이스 사유 칸에 넣는 글자: 조퇴·외출·지각은 문장과 상관없이 **항상 «개인 용무»**.
- 병조퇴·병외출·병지각은 문장과 상관없이 **항상 «병원 진료»**.

**해석하는 곳**: 스쿨보드 화면(브라우저) 안의 규칙 코드로 해석한다. 외부 서비스로 문장을 보내지 않는다. 규칙으로 안 되는 문장은 미리 보기에서 빨갛게 표시하고, 선생님이 칸을 직접 고친다.

**설정에 둘 값** 【채워 주세요】
- 출근 시각: **08:30** / 퇴근 시각: **16:30** (설정에서 바꿀 수 있게)
- 연락처: 이 컴퓨터의 `%LOCALAPPDATA%\SchoolBoard\neis\config.json` 에 `"phone"` 으로 저장해 둠 (저장소·GitHub 에는 적지 않음)
- `내역` 탭: 남은 연가 일수, 최근 신청 목록(날짜·종류·결재 상태)을 보여 준다. [새로고침]을 누르면 다시 읽어 온다.

## 5. 이 컴퓨터의 복무 도우미 (만들 것)

- `neis-login/` 안에서 로그인 코드를 함께 쓰는 Node 프로그램으로 만든다.
- 스쿨보드와는 기존 폴더 열기 도우미처럼 **이 컴퓨터 안 주소(127.0.0.1) + 비밀 열쇠**로만 통신한다. 다른 웹사이트는 요청할 수 없게 한다.
  - 포트와 열쇠 보관 방식은 만들 때 정한다(기존 47615와 겹치지 않게).
- 같은 신청을 두 번 상신하지 않도록, 요청마다 고유 번호를 붙이고 처리한 번호는 기억한다.

## 6. 안전 규칙

1. **상신 전 마지막 확인**: 스쿨보드의 요약 확인 창에서 [예]를 누른 요청만 상신한다.
2. **화면 대조**: 나이스 칸에 넣은 뒤, 칸에 실제로 들어간 값을 다시 읽어 스쿨보드 입력값과 하나라도 다르면 **상신하지 않고 멈춘다**.
3. **한 번만**: 상신 단추는 한 번만 누른다. 결과가 애매하면(응답 없음, 화면 바뀜) 다시 누르지 않고, 크롬 창을 그대로 둔 채 선생님께 확인을 부탁한다.
4. **예상 못한 화면**에서는 멈춘다. 알림 창이나 팝업, 칸 이름이 다르면 크롬 창을 닫지 않고 알림 창으로 이유를 알린다.
5. 로그인 규칙은 자동로그인 지시문을 따른다(암호 미노출, 실패 시 재시도 안 함).
6. 복무 기록(신청 내용·결과)은 이 컴퓨터(`%LOCALAPPDATA%\SchoolBoard\neis\`)에만 두고, GitHub에는 올리지 않는다.
